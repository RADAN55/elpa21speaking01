SCHOOL LIFE: 25 FOUR-SKILL ACTIVITIES (GRADES 9-12)

UNZIP FIRST. Upload the extracted index.html to the main folder of your existing workbook repository, replacing its previous index.html. Do not upload the ZIP as the website. Keep the filename exactly index.html.

All images, text, questions, and interactive code are inside that one HTML file. No build command or extra image folder is needed. Open your published GitHub Pages website, not the repository's code preview. If the old page is still displayed, refresh it.

WHAT IS INCLUDED
25 original reading passages with two questions and an evidence response each.
25 original listening messages with two questions each.
25 picture-based speaking tasks with planning and follow-up questions.
25 writing prompts with planning, drafts, revision checks, and final responses.
100 reading/listening questions with practice feedback and explanations.
All 10 original lifelike images, bilingual vocabulary, save/restore, response reports, and printing.

LISTENING
Play buttons use browser/device text-to-speech in English. This is synthesized narration, not recorded human audio. Available voices and offline playback vary by device; an internet connection may be required by a voice. Select a voice/speed under How to use + audio setup. Play one message at a time. Stop or change activities to stop it.
Every message has a transcript that a teacher can read aloud if audio is unavailable. For listening practice, keep it closed during the first attempt. The scripts also appear when printing for teacher read-aloud use.

CLASSROOM USE
Complete Read, Listen, Speak, and Write in each activity. Check each part's completion box. Speaking completion from an older backup does not mark the other skills finished. Answer feedback allows retries; it is not a secure assessment.
Writing and speaking require teacher/partner feedback. Word counts and checklists are not ELPA21 proficiency scores. No student audio recording is included.

SAVING AND SUBMISSION
Work stays in the same browser/device where storage is available. Download my work saves a JSON backup for Restore saved work. Download response report creates a text report with all four-skill responses and objective practice results. Submit through your teacher's usual method. Nothing is sent to a teacher automatically.
Older speaking-only backups can be restored. Save a current backup before replacing browser answers with an older backup.

These are original ELPA21-style classroom materials, not official test items or a complete test simulation. The photographs are AI-generated.
